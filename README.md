## Tech Stack

**Backend**
- FastAPI
- Uvicorn (ASGI server)
- SQLAlchemy (ORM)
- Pydantic (data validation)
- (optional) PostgreSQL / SQLite

**Frontend**
- React 18+
- Vite (build tool)
- React Router (if used)
- Axios or Fetch (API calls)
